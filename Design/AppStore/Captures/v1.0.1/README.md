# 1.0.1 실제 화면 촬영본

TCON Maker 1.0.1 (2)의 실제 시뮬레이터 화면이다. 가상의 성인 예시 사진을 사용했고 원본 배경 모드로 촬영했다. PNG는 수정하지 않았으며 홍보 이미지에서만 시간·배터리 영역을 제외한다.

- iPad Pro 13형 / iOS 27: 세로 8장, 가로 편집·홈 2장.
- iPhone 18 Pro Max / iOS 27: 세로 8장.
- `manifest.json`: 촬영 버전·크기·SHA-256.
- 업로드용 이미지는 상위 `ko-KR` 폴더의 기기별 7장이다.

아이패드 가로·세로 배치, 최대 글자 크기, 아이패드 mini 좁은 화면, 아이폰 사진 선택 진입을 관련 UI 테스트 5건으로 확인했다. 물리 아이패드와 실제 Split View 창 크기 조절은 수행하지 않았다.
