# App Store 한국어 홍보 이미지

앱 로고를 중앙에 배치한 프로모션 표지와 실제 TCON Maker 1.0.0 (1) 캡처에 기능별 제목·설명 및 기기 목업을 적용한 홍보 이미지이다. 큰 하단 서린 로고는 첫 표지에만 배치하고 배경에 어울리는 부드러운 단색으로 표현했다. 중앙 앱 로고의 크기와 대비도 낮췄다. 기능 소개 이미지의 상단 브랜드 행·작은 분류 문구와 하단 브랜드 문구·서명은 제거했다. `index.html`에서 전체 결과를 확인한다. 정지 이미지이며 App Preview 동영상은 아니다.

## 최종 업로드 파일

`ko-KR` 아래 기기별 폴더의 `01`부터 `07`까지 PNG를 순서대로 업로드한다. 각 크기 7장(표지 1장 + 기능 소개 6장), 총 21장이다. [Apple 스크린샷 사양](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)의 허용 크기를 2026-10-13에 확인했다.

| 폴더 | 크기 | 화면 출처 |
| --- | --- | --- |
| iPhone-Medium-1179x2556 | 1179 × 2556 | iPhone 18 Pro Max 시뮬레이터의 실제 앱 UI를 동일 디자인으로 구성 |
| iPhone-Large-1320x2868 | 1320 × 2868 | iPhone 18 Pro Max 시뮬레이터의 실제 앱 UI |
| iPad-13-2064x2752 | 2064 × 2752 | iPad Pro 13형 시뮬레이터의 실제 앱 UI |

1. 프로모션 표지 — 사진 준비는 가볍게, 심사에 더 집중하세요
2. 사진 준비 — 심사 사진 준비, 이제 간편하게
3. 규격 설정 — 원하는 규격으로 한 번에 맞춰요
4. 사진 편집 — 얼굴 위치부터 구도까지 섬세하게
5. 폴더 관리 — 심사일·수련반별로 차곡차곡 정리해요
6. 여러 장 선택 — 필요한 사진만 골라서 한 번에
7. 사진 저장 — 사진·파일·ZIP으로 편하게 저장해요

모든 PNG는 RGB·불투명이다. iPhone에는 얇고 균일한 베젤·측면 버튼·둥근 화면과 화면 내부 다이내믹 아일랜드를 적용한 목업을, iPad에는 해당 캡처 비율의 태블릿 목업을 사용했다. 아이폰의 상단 안전 영역과 하단 홈 표시 영역을 캡처 바깥에 구성하여 다이내믹 아일랜드가 앱 컨트롤을 가리지 않는다. 시간·배터리 아이콘은 추가하지 않는다. 표지 로고의 색상·투명도 조정은 HTML/CSS 표시 효과이며 원본 로고 파일은 변경하지 않는다. 실제 앱 UI에 이미 포함된 로고는 캡처 그대로 유지한다. 홍보 문구는 앱 화면 바깥에 배치했다. UI 글자·버튼·사진 보정 결과를 다시 그리거나 교체하지 않았고, 가상의 성인 예시 사진만 사용했다. 화면 안의 사진은 해당 캡처에서 선택한 원본 배경 모드이다.

iPhone 캡처의 상단 180px, iPad 캡처의 상단 58px를 CSS 표시 영역에서 제외하여 시간·배터리·상태 아이콘을 숨겼다. 하단 여백은 각각 16px, 28px를 제외했다. 앱 화면은 비율을 유지해 축소했으며 원본 캡처 파일은 수정하지 않았다. 상태 표시줄 제외는 이번 디자인 요청에 따른 것이며 Apple의 필수 규칙이라는 의미는 아니다.

## 원본과 재생성

- `Captures/`: 기존 촬영본 24장, 당시 안내와 원본 해시. 업로드용 최종 이미지가 아니다.
- `Source/promotion.html`: 편집 가능한 HTML/CSS 디자인 및 한국어 문구. `?device=iPad-13-2064x2752&slide=2`처럼 기기와 0부터 시작하는 장 번호를 지정할 수 있다.
- `Overview/`: 기기별 7장 모아보기. 업로드용이 아니다.
- `manifest.json`: 최종 출력 크기·투명도·해시·사용 캡처·자른 범위를 기록한다.
- `Scripts/render_appstore.mjs`: 저장소 루트에 있는 이미지 생성기.

macOS의 Apple SD Gothic Neo 글꼴과 Node.js, Playwright, Sharp가 필요하다. 브라우저는 Playwright Chromium 또는 설치된 Chrome을 사용할 수 있다. 저장소 루트에서 실행한다.

```sh
# playwright와 sharp를 찾을 수 있는 환경에서 실행
TCON_RENDER_BROWSER='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
  node Scripts/render_appstore.mjs
```

패키지가 별도 경로에 설치되어 있으면 `TCON_RENDER_MODULES`에 해당 `node_modules` 경로를 지정한다. 생성기는 이미지 로딩·표지와 기능 화면의 요소 겹침·캔버스 이탈·21개 파일의 크기와 RGB 불투명 여부를 검사하며, 갤러리와 모아보기까지 재생성한다.

이번 변경은 앱 구현을 수정하지 않는다. 사용자 요청에 따라 이전 앱 테스트를 반복하지 않고 최종 이미지 21장의 크기·투명도·배치 및 원본 캡처 24장의 해시 보존을 확인했다. App Store Connect 업로드·심사 제출은 수행하지 않았다.
