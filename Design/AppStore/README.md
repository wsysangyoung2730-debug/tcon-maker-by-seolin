# App Store 한국어 홍보 이미지

앱 로고를 중앙에 배치한 프로모션 표지와 실제 TCON Maker 1.0.2 (4) 캡처에 기능별 제목·설명 및 기기 목업을 적용한 홍보 이미지이다. 큰 하단 서린 로고는 첫 표지에만 배치하고 배경에 어울리는 부드러운 단색으로 표현했다. 중앙에는 사용자 제공 새 TCON 로고를 원래 색상으로 배치했다. 기능 소개 이미지의 상단 브랜드 행·작은 분류 문구와 하단 브랜드 문구·서명은 제거했다. `index.html`에서 전체 결과를 확인한다. 정지 이미지이며 App Preview 동영상은 아니다.

## 최종 업로드 파일

`ko-KR` 아래 기기별 폴더의 `01`부터 `07`까지 PNG를 순서대로 업로드한다. 각 크기 7장(표지 1장 + 기능 소개 6장), 총 21장이다. [Apple 스크린샷 사양](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)의 허용 크기를 2026-10-13에 확인했다.

| 폴더 | 크기 | 화면 출처 |
| --- | --- | --- |
| iPhone-Medium-1179x2556 | 1179 × 2556 | iPhone 18 Pro Max 시뮬레이터의 실제 앱 UI를 동일 디자인으로 구성 |
| iPhone-Large-1320x2868 | 1320 × 2868 | iPhone 18 Pro Max 시뮬레이터의 실제 앱 UI |
| iPad-13-2064x2752 | 2064 × 2752 | iPad Pro 13형 시뮬레이터의 실제 앱 UI |

1. 프로모션 표지 — 사진 준비는 가볍게, 심사에 더 집중하세요
2. 사진 준비 — 심사 사진 준비, 이제 간편하게
3. 규격 설정 — 원하는 규격으로 한 번에 맞춰요
4. 사진 편집 — 얼굴 위치부터 구도까지 섬세하게
5. 폴더 관리 — 심사일·수련반별로 차곡차곡 정리해요
6. 여러 장 선택 — 필요한 사진만 골라서 한 번에
7. 사진 저장 — 사진·파일·ZIP으로 편하게 저장해요

모든 PNG는 RGB·불투명이다. iPhone에는 얇고 균일한 베젤·측면 버튼·둥근 화면과 화면 내부 다이내믹 아일랜드를 적용한 목업을, iPad에는 해당 캡처 비율의 태블릿 목업을 사용했다. 아이폰은 원본 전체 캡처의 종횡비로 디스플레이를 구성하고 별도 상·하단 여백 없이 가장자리까지 채운다. 다이내믹 아일랜드는 원본 상태 표시줄 영역 안에 배치하여 앱 컨트롤을 가리지 않는다. 시간·배터리 아이콘은 추가하지 않는다. 표지 로고의 색상·투명도 조정은 HTML/CSS 표시 효과이며 원본 로고 파일은 변경하지 않는다. 실제 앱 UI에 이미 포함된 로고는 캡처 그대로 유지한다. 홍보 문구는 앱 화면 바깥에 배치했다. UI 글자·버튼·사진 보정 결과를 다시 그리거나 교체하지 않았고, 가상의 성인 예시 사진만 사용했다. 화면 안의 사진은 해당 캡처에서 선택한 원본 배경 모드이다.

iPhone은 전체 캡처(1320×2868)를 비율 그대로 표시하고 상단 180px의 시간·배터리 영역만 해당 화면에서 확인한 배경색으로 가린다. 별도 흰 띠나 홈 표시 영역을 덧붙이지 않는다. 설정 화면의 실제 모달 배경과 둥근 모서리는 원본 UI 그대로이다. iPad는 기존처럼 상단 58px와 하단 28px를 표시 영역에서 제외한다. 앱 화면은 비율을 유지해 축소했으며 원본 캡처 파일은 수정하지 않았다. 상태 표시줄 제외는 이번 디자인 요청에 따른 것이며 Apple의 필수 규칙이라는 의미는 아니다.

## 원본과 재생성

- `Captures/v1.0.2/`: 새 로고·브랜드가 적용된 실제 촬영본 18장과 원본 해시.
- `Captures/v1.0.1/`: 이전 촬영본 18장을 보존한다.
- `Captures/ko-KR/`: 이전 1.0.0 촬영본 24장을 그대로 보존한다.
- `Source/promotion.html`: 편집 가능한 HTML/CSS 디자인 및 한국어 문구. `?device=iPad-13-2064x2752&slide=2`처럼 기기와 0부터 시작하는 장 번호를 지정할 수 있다.
- `Overview/`: 기기별 7장 모아보기. 업로드용이 아니다.
- `manifest.json`: 최종 출력 크기·투명도·해시·사용 캡처·자른 범위·상태 표시줄 처리 범위를 기록한다.
- `Scripts/render_appstore.mjs`: 저장소 루트에 있는 이미지 생성기.

macOS의 Apple SD Gothic Neo 글꼴과 Node.js, Playwright, Sharp가 필요하다. 브라우저는 Playwright Chromium 또는 설치된 Chrome을 사용할 수 있다. 저장소 루트에서 실행한다.

```sh
# playwright와 sharp를 찾을 수 있는 환경에서 실행
TCON_RENDER_BROWSER='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
  node Scripts/render_appstore.mjs
```

패키지가 별도 경로에 설치되어 있으면 `TCON_RENDER_MODULES`에 해당 `node_modules` 경로를 지정한다. 생성기는 이미지 로딩·표지와 기능 화면의 요소 겹침·캔버스 이탈·21개 파일의 크기와 RGB 불투명 여부를 검사한다. 아이폰 캡처와 디스플레이 영역 일치, 아일랜드와 앱 콘텐츠의 비중첩, 같은 브랜드 개정에서 표지의 해시 보존도 확인하며, 갤러리와 모아보기까지 재생성한다.

새 로고·팔레트를 반영한 실제 앱 화면을 촬영한다. 촬영 테스트는 사진 편집·선택·폴더 이동·저장 진입과 아이패드 가로·세로 배치를 함께 확인한다. 온보딩·다크 모드 최대 글자 크기도 관련 테스트로 확인하고 결과를 브랜드 변경 기록에 남긴다. 최종 이미지 21장의 크기·투명도·배치 및 표지 재생성 일관성을 검사한다.

## 브랜드 개정

2026-10-19 새 로고의 메인 파랑 `#1B34A8`과 보조 파랑 `#6071C2`를 반영했다. 원본은 `Design/Brand`에 보존하며 최종 manifest에 브랜드 원본 해시·표현 개정·앱 버전·빌드를 기록한다. 로고가 바뀐 새 개정에서 표지 기준을 갱신하고 같은 개정의 후속 재생성에서는 표지 해시를 다시 검사한다. 이전 표지는 Git 이력에서 확인할 수 있다.
