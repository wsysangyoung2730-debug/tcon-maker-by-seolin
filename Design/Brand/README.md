# TCON Maker 브랜드

2026-10-19 사용자 제공 `Tcon Maker new 로고.png`의 원본은 `tcon-logo-original.png`이다. 원본 1080×1080 RGB를 그대로 보존하고 화면용 TCONLogo에 적용했다. AppIcon은 같은 이미지를 Lanczos로 1024×1024 리샘플링한 불투명 RGB PNG이다. 배지·모서리·배경을 별도로 합성하지 않는다.

- 메인 파랑: `#1B34A8`. 주요 버튼, 밝은 화면 링크·선택·탭·슬라이더.
- 보조 파랑: `#6071C2`. 예시 사진 안내 영역의 10% 배경색.
- 다크 모드 강조: `#AEBBFF`. 어두운 바탕에서 링크·아이콘·선택 상태 식별.
- 주요 버튼의 흰색 글자, 삭제·오류·완료의 의미 색상, 기기 기본 배경은 유지한다.
- 서린태권도 하단 서명은 별도 원본 에셋을 유지한다.

`palette.json`에 원본 해시와 색상 기준을 기록한다. SwiftUI 공통 색상은 `TCONMaker/Shared/Components/Components.swift`에서 관리한다. 홍보 이미지도 동일 팔레트와 실제 새 앱 화면을 사용한다.
