# 출시 점검 결과 — 2026-10-13

TCON Maker 1.0.0 (1), 최소 iOS 17, iPhone·iPad 대상으로 코드와 번들을 점검했다. 개인정보처리방침 웹사이트 제작·검증은 요청에 따라 제외했다. App Store 업로드·심사 제출은 하지 않았다.

## 수정한 사항

- 배포 권한을 확인하지 못한 RVM·Selfie 인물 분리 모델을 제거하고 Apple Vision으로 교체했다. 흰색·투명·원본 배경 및 크롭·밝기·회전·저장 기능을 유지했다. 얼굴 모델의 공식 MIT 출처와 포함 라이브러리 라이선스를 [출처 문서](THIRD_PARTY.md)에 정리했다.
- 사진 처리 시간 초과, WebKit 프로세스 중단·로딩 실패 이후 다시 준비하기와 사진함 복원을 보강했다. 연속 편집의 마지막 입력을 저장 전에 기다리도록 수정했다.
- 가져오기·내보내기의 권한 거절 안내와 설정 이동, 파일명 길이·중복 처리, HEIC/EXIF 방향 정규화 및 원본 보존을 확인했다.
- 오류·일반 안내를 하나의 알림 경로로 통합했다. 카메라 버튼 전체에 터치 영역을 적용했다.
- 홈의 규격·사진 선택·촬영·안내·서린 로고를 같은 스크롤 영역에 놓고 예시 카드에도 동일한 사진 선택창을 연결했다. 폴더·사진 선택 화면의 중복 삭제 메뉴를 제거했다.
- 앱 버전 표시·지원 링크·라이선스 고지를 정리하고 큰 글자에서 설정을 조작할 수 있도록 보강했다. 배포 아카이브에 테스트 대상이 포함되지 않도록 스킴을 수정했다.

## 검증 환경과 결과

검증 기록은 이번 작업에서 수행한 자동 테스트·직접 확인 범위를 뜻하며 모든 기기·사진의 품질이나 App Review 승인을 보장하지 않는다.

| 범위 | 확인 결과 |
| --- | --- |
| iPhone 14 Pro, iOS 26.5 | 모델·사진 엔진·사진함·성능·복구 테스트 14개 통과. Apple 인물 분리, 흰색 JPG·투명 PNG·ZIP, 캐시·편집 복원, 엔진 중단 및 시간 초과 복구 포함 |
| iOS 27 iPhone 시뮬레이터 | 단위·통합 테스트 11개 통과, Apple 인물 분리 관련 3개는 런타임 미지원으로 건너뛰고 위 실기기에서 통과 확인 |
| 주요 UI | 온보딩·튜토리얼·홈 및 규격 설정·폴더 생성/이름 변경/이동/재실행·선택 삭제·저장 진입을 실제 iPhone에서 검증 |
| 홈 사진 선택 | 예시 카드와 기본 버튼 모두 시스템 선택창 열기·취소를 iPhone 및 iPad에서 검증 |
| 삭제 방식 | 하단 버튼 1회로 선택 폴더·사진 삭제, 폴더 사진의 미분류 이동, 재실행 후 남은 항목 일치 확인 |
| 접근성 | 최대 글자 크기·다크 모드에서 규격 선택과 적용을 검증. 전체 VoiceOver 실기기 탐색은 남은 수동 점검에 포함 |
| 스크린샷 | 실제 iPhone 및 iPhone·iPad 시뮬레이터에서 8장씩 촬영. 업로드용 크기와 RGB 불투명 PNG 검증 |
| Release | 일반 iOS 기기용 unsigned Archive 성공. 배포 서명·App Store Connect 검증·업로드는 미수행 |

카메라 미지원 안내 테스트는 DEBUG 실행 인자로 미지원 상태를 명시하여 실제 iPhone과 시뮬레이터에서 같은 안내 경로를 검증한다. iOS 27 시뮬레이터는 카메라 사용 가능 여부가 `true`일 수 있어 ‘시뮬레이터면 항상 미지원’이라는 테스트 가정을 제거했다. 실제 카메라 촬영·권한 팝업까지 검증한 것으로 간주하지 않는다.

원본 이미지의 HEIC/EXIF 방향 정규화, 내보내기 파일의 GPS 제거, JPG 용량 제한, 투명 PNG, ZIP 및 중복 이름을 자동 검증했다. 생성된 성인 예시에서 흰색·투명 배경 결과도 확인했다. 기존 모델과 픽셀 결과가 같다는 의미는 아니며 다양한 실제 수련생 사진의 경계 품질은 별도 확인이 필요하다.

## 번들·개인정보 점검

- Bundle ID `com.seolin.tconmaker`, 버전 1.0.0 (1), iOS 17.0 이상, iPhone·iPad 지원.
- 카메라 사용 및 사진 추가 권한 설명 포함. 사진 가져오기는 시스템 PhotosPicker로 선택 항목만 전달받는다.
- 1024 × 1024 불투명 앱 아이콘, PrivacyInfo.xcprivacy, 오픈소스 고지 및 로컬 엔진 리소스 포함.
- UserDefaults 사용 사유 CA92.1 선언. 사진·얼굴 분석 결과를 외부로 전송하는 코드, 광고·추적·분석 SDK 없음. 엔진의 네트워크 연결은 CSP로 차단한다.
- 분석 캐시는 기기 백업에서 제외하고 작업 원본은 앱 내부에 보관한다. 원본 보관함 파일은 덮어쓰지 않는다.
- Release 실행 파일에 DEBUG 전용 테스트 실행 인자가 없고 테스트 번들도 포함하지 않는다.
- 로그인·계정·구독·인앱결제 기능이 없어 계정 삭제나 구매 복원 구현 대상은 아니다.

## 제출 전 남은 확인

1. 배포 인증서·프로비저닝으로 Archive를 서명하고 App Store Connect Validate App 및 TestFlight에서 설치·실행한다. 현재 아카이브 성공만으로 제출 가능 판정을 대신할 수 없다.
2. 실제 기기에서 카메라 최초 허용·거절·재허용 및 촬영, iCloud 사진 다운로드, 사진 앱 추가 권한과 저장, 파일 앱 저장·공유 취소/완료를 마지막으로 확인한다. 시스템 파일 선택·공유 대상 앱까지의 전체 조합은 자동화하지 않았다.
3. iOS 17 기기·저메모리 환경·다양한 얼굴/도복/머리카락/배경의 다중 사진으로 처리 품질과 장시간 작업을 확인한다. 실기기 자동 검증은 iPhone 14 Pro / iOS 26.5에 한정했다.
4. VoiceOver로 전체 작업을 실제 기기에서 확인한다. 최대 글자 설정 통과가 모든 접근성 조합을 대신하지 않는다.
5. TCON 및 여권 제출 기관의 최신 규격을 대조한다. 프리셋은 편집 도구이며 공식 승인 여부를 판정하지 않는다.
6. App Store Connect의 연령 등급·앱 개인정보 답변·지원 URL·가격·지역·저작권·개인정보처리방침 URL을 입력하고 실제 제출 빌드와 스크린샷을 맞춘다.
