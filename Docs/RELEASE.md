# 출시 점검 결과 — 2026-10-13

TCON Maker 1.0.0 (1), 최소 iOS 17, iPhone·iPad 대상으로 코드와 번들을 점검했다. 개인정보처리방침 웹사이트 제작·검증은 요청에 따라 제외했다. 이후 배포 서명·App Store Connect 업로드와 1.0.0 (1) 버전 연결을 완료했다. 심사 제출은 하지 않았으며 [업로드 기록](APP_STORE_UPLOAD.md)에 상태를 정리했다.

## 수정한 사항

- 배포 권한을 확인하지 못한 RVM·Selfie 인물 분리 모델을 제거하고 Apple Vision으로 교체했다. 흰색·투명·원본 배경 및 크롭·밝기·회전·저장 기능을 유지했다. 얼굴 모델의 공식 MIT 출처와 포함 라이브러리 라이선스를 [출처 문서](THIRD_PARTY.md)에 정리했다.
- 사진 처리 시간 초과, WebKit 프로세스 중단·로딩 실패 이후 다시 준비하기와 사진함 복원을 보강했다. 연속 편집의 마지막 입력을 저장 전에 기다리도록 수정했다.
- 가져오기·내보내기의 권한 거절 안내와 설정 이동, 파일명 길이·중복 처리, HEIC/EXIF 방향 정규화 및 원본 보존을 확인했다.
- 오류·일반 안내를 하나의 알림 경로로 통합했다. 카메라 버튼 전체에 터치 영역을 적용했다.
- 홈의 규격·사진 선택·촬영·안내·서린 로고를 같은 스크롤 영역에 놓고 예시 카드에도 동일한 사진 선택창을 연결했다. 폴더·사진 선택 화면의 중복 삭제 메뉴를 제거했다.
- 앱 버전 표시·지원 링크·라이선스 고지를 정리하고 큰 글자에서 설정을 조작할 수 있도록 보강했다. 배포 아카이브에 테스트 대상이 포함되지 않도록 스킴을 수정했다.

카메라 미지원 안내 테스트는 DEBUG 실행 인자로 미지원 상태를 명시하여 실제 iPhone과 시뮬레이터에서 같은 안내 경로를 검증한다. iOS 27 시뮬레이터는 카메라 사용 가능 여부가 `true`일 수 있어 ‘시뮬레이터면 항상 미지원’이라는 테스트 가정을 제거했다. 이 미지원 상태 테스트 자체를 실제 촬영 검증으로 간주하지 않는다. 별도로 Tom의 iPhone에서 카메라 권한 거절·허용과 촬영 결과의 편집 화면 진입을 확인했다.

원본 이미지의 HEIC/EXIF 방향 정규화, 내보내기 파일의 GPS 제거, JPG 용량 제한, 투명 PNG, ZIP 및 중복 이름을 자동 검증했다. 생성된 성인 예시에서 흰색·투명 배경 결과도 확인했다. 기존 모델과 픽셀 결과가 같다는 의미는 아니며 다양한 실제 수련생 사진의 경계 품질은 별도 확인이 필요하다.

## 번들·개인정보 점검

- Bundle ID `com.seolin.tconmaker`, 버전 1.0.0 (1), iOS 17.0 이상, iPhone·iPad 지원.
- 카메라 사용 및 사진 추가 권한 설명 포함. 사진 가져오기는 시스템 PhotosPicker로 선택 항목만 전달받는다.
- 1024 × 1024 불투명 앱 아이콘, PrivacyInfo.xcprivacy, 오픈소스 고지 및 로컬 엔진 리소스 포함.
- UserDefaults 사용 사유 CA92.1 선언. 사진·얼굴 분석 결과를 외부로 전송하는 코드, 광고·추적·분석 SDK 없음. 엔진의 네트워크 연결은 CSP로 차단한다.
- 분석 캐시는 기기 백업에서 제외하고 작업 원본은 앱 내부에 보관한다. 원본 보관함 파일은 덮어쓰지 않는다.
- Release 실행 파일에 DEBUG 전용 테스트 실행 인자가 없고 테스트 번들도 포함하지 않는다.
- 로그인·계정·구독·인앱결제 기능이 없어 계정 삭제나 구매 복원 구현 대상은 아니다.

## 제출 전 남은 확인

1. TestFlight에서 배포 빌드 설치·실행을 확인한다. 배포 서명·App Store Connect 업로드 검증 및 빌드 처리·버전 연결은 완료했으며, TestFlight 설치 검증을 대신하지 않는다.
2. 카메라의 X 버튼으로 닫기, iCloud 원본 다운로드, 파일 앱의 선택한 위치에 최종 저장, 다른 앱으로 공유 완료를 확인한다. 사진 추가 권한 허용·거절과 예시 2장 저장은 Tom의 iPhone에서 확인했다. 시스템 파일 선택·공유 대상 앱까지의 전체 조합은 자동화하지 않았다.
3. iOS 17 기기·저메모리 환경·다양한 얼굴/도복/머리카락/배경의 다중 사진으로 처리 품질과 장시간 작업을 확인한다. 엔진 검증은 iPhone 14 Pro / iOS 26.5에서 수행했다. 추가 UI와 권한 검증에는 iPhone 17 / iOS 26.6을 사용했다. 사용자 요청에 따라 이미 통과한 전체 테스트를 추가 기기에서 반복하지 않았다.
4. VoiceOver로 전체 작업을 실제 기기에서 확인한다. 최대 글자 설정 통과가 모든 접근성 조합을 대신하지 않는다.
5. TCON 및 여권 제출 기관의 최신 규격을 대조한다. 프리셋은 편집 도구이며 공식 승인 여부를 판정하지 않는다.
6. 제외 요청한 개인정보처리방침 URL을 입력한 뒤 심사를 제출한다. 연령 등급·앱 개인정보 답변·지원 URL·가격·지역·저작권과 실제 앱에 맞춘 스크린샷은 등록 완료했다. App Store Connect 필수값 검사에서도 개인정보처리방침 URL만 누락으로 표시되었다.

## 추가 UI 변경과 검증 범위

온보딩의 시작 버튼 2개와 서린 로고를 원본 보관 설명 아래 본문으로 옮겼다. Tom의 iPhone에서 버튼 배치·시작·재실행 완료 기록을 확인했다. 사진 앱에 예시 사진 2장 저장과 권한 거절·허용 안내도 통과했다. 파일·공유 창 취소 후 저장 화면으로 복귀하는 동작도 통과했다. iCloud 원본 다운로드·파일 최종 저장·다른 앱으로 공유 완료는 별도 확인 대상이다.

카메라 화면의 X 버튼은 iOS 26.6에서 자동화에 이름 있는 버튼으로 노출되지 않았다. 녹화로 위치를 확인해 테스트를 보완했으나, 최종 재실행은 기기 잠금으로 시작하지 못했다. 따라서 카메라 취소 자동화는 통과로 계산하지 않는다. 실제 카메라 표시와 촬영 결과 편집 진입은 앞선 실행에서 확인했다.

실기기 저장 검사는 일반 테스트에서 실행되지 않는다. 승인된 기기에 한해 `TEST_RUNNER_TCON_DEVICE_IO_TESTS=1`을 지정하고 `DeviceExportUITests`를 선택해야 한다. 예시 사진 두 장을 사진 앱에 추가하며, 앱의 카메라/사진 권한을 초기화해 허용·거절을 검사한다. 카메라 닫기의 좌표 대체 경로는 확인한 iOS 26.6 세로 iPhone 화면에 한정된다.
