# App Store 제출 전 남은 준비

이 저장소는 개발용 iOS 앱이며 App Store 배포·제출은 수행하지 않았습니다.

- Apple Developer Team 선택, 확정 Bundle Identifier, 서명 및 프로비저닝
- 제출 기관의 TCON 크기·파일 형식·최대 용량 최신 안내 확인
- 원본 HTML의 얼굴·분리 모델별 출처와 가중치 재배포 조건 확인 (원본에 모든 조건이 명시되지 않음)
- 실제 iPhone에서 카메라, HEIC/iCloud 원본 다운로드, 사진 접근 허용/거부/제한, 파일 저장, 공유 완료 확인
- 다양한 도복·헤어스타일·배경의 실제 사진으로 분리 품질 및 저메모리 다중 사진 작업 확인
- 앱 개인정보 안내를 공개 URL로 게시하고 App Store Connect 개인정보 답변 작성
- 스토어 설명, 지원 URL, 연령 등급, 스크린샷, TestFlight 테스트
- VoiceOver·큰 글자·다크 모드 실기기 최종 점검

사진 처리와 임시 저장은 기기 안에서 이루어집니다. 로컬 모델만 사용하며 로그인, 광고, 분석 SDK 및 서버 저장 기능은 포함하지 않습니다. `PrivacyInfo.xcprivacy`에는 설정 저장에 사용하는 UserDefaults 사유를 기재했습니다.
