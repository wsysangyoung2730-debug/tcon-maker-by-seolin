# iPad 홈 세로 배치 (#56)

- 작업 브랜치: `fix/#56-ipad-home`
- 다음 출시 준비 버전: 1.0.2 (4)
- App Store Connect 이미지 교체와 빌드 업로드는 후속 작업이다.

## 변경

iPad 홈의 좌우 분할을 제거했다. 로고와 안내, 예시 사진, 사진 규격, 사진 선택·촬영, 여러 장 안내와 오른쪽 서린 로고가 같은 스크롤 안에서 세로로 이어진다. 넓은 창에서는 전체 너비를 최대 640pt로 제한하고 예시 사진을 176×220pt로 표시한다. 좁은 창에서는 기존 560pt 제한과 작은 사진 크기를 유지한다. 가로 화면도 같은 순서로 스크롤할 수 있다.

예시 사진과 사진 선택 버튼의 사진 보관함 연결, 규격 버튼의 전체 설정 연결을 유지한다. 사진 편집 화면의 넓은 iPad 배치는 변경하지 않았다.

## 검증 및 캡처

`HomeImportUITests/testExampleCardAndPrimaryButtonOpenPhotoLibrary`에서 iPad 세로 홈의 사진 → 규격 → 선택 → 촬영 순서와 가운데 정렬, 주요 버튼 노출을 확인한다. 규격에서 설정을 열고 닫은 뒤 예시 사진과 사진 선택 버튼 각각의 사진 보관함 접근을 확인한다.

실제 촬영 첨부 중 `store-01-home`, `store-08-home-actions`, `store-07-settings`만 원본 PNG로 가져온다. 이전 전체 캡처 테스트의 홈 검증도 새 세로 순서로 맞췄다. 이번 범위에서는 전체 사진 처리 테스트를 반복하지 않는다.

홍보 이미지 2페이지에는 새 홈을 반영하고, 3페이지도 설정 뒤의 홈 배경이 일치하도록 갱신한다. 다른 화면과 표지는 기존 이미지를 유지한다. 새 최종 이미지는 기존과 같은 기기 목업, 제목·설명, 시간·배터리 제외 처리를 사용한다.
