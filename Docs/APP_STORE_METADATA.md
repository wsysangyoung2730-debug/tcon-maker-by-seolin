## 설명

서린태권도에서 만든 TCON Maker로 심사 등록용 사진을 준비해 보세요.

사진을 선택하거나 촬영한 뒤, 얼굴 위치와 사진 비율을 맞추고 결과를 직접 확인할 수 있습니다. 사진은 기기 안에서 처리하며 원본 사진을 덮어쓰지 않습니다.

- TCON·증명사진·여권사진 규격 프리셋과 가로·세로 크기 조절
- 얼굴 위치에 맞춘 자동 구도, 확대·이동·회전·밝기 조절
- Apple 사진 분석 기능을 이용한 흰색·투명 배경, 원본 배경 유지
- 심사일·수련반별 폴더 생성과 사진 이동
- 사진을 길게 눌러 여러 장 선택 후 저장 또는 삭제
- JPG·투명 PNG 저장, 여러 장을 ZIP 파일로 내보내기
- 사진 앱·파일 앱 저장 및 다른 앱으로 공유
- 처음 사용하는 분을 위한 온보딩과 연습형 사용 안내

자동 맞춤은 편집을 돕는 기능입니다. 제출 기관의 최신 규격과 결과 사진의 머리카락·얼굴·도복 경계를 확인해 주세요. TCON 또는 여권 사진의 공식 승인 여부를 판정하지 않습니다.

## 심사 메모

로그인, 계정 생성, 유료 결제, 광고가 없습니다. 네트워크 연결 없이 사진을 편집할 수 있습니다.

1. 첫 실행 화면에서 시작하거나 사용법을 연습합니다.
2. 홈의 예시 사진 카드 또는 ‘사진 선택하기’를 눌러 사진을 선택합니다. 실제 기기에서는 카메라도 사용할 수 있습니다.
3. 사진 규격과 배경·구도·밝기를 조정합니다.
4. 파일 탭에서 폴더를 만들고 사진을 이동합니다. 사진을 길게 누르면 여러 장을 선택할 수 있습니다.
5. 저장 화면에서 사진 앱 또는 파일 앱을 선택합니다. 여러 사진은 ZIP으로 저장할 수 있습니다.

사진 보관함 선택은 시스템 선택창을 사용하며 전체 보관함 읽기 권한을 요구하지 않습니다. 촬영 시 카메라 권한, 사진 앱에 저장할 때 사진 추가 권한을 요청합니다. 사진을 외부 서버로 보내지 않습니다.

Apple Vision의 인물 분리는 실제 iPhone/iPad에서 확인해 주세요. 시뮬레이터의 해당 기능에는 런타임 제한이 있으며 원본 배경 편집은 지원합니다.
