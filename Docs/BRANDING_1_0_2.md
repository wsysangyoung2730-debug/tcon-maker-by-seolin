# 1.0.2 새 로고와 브랜드 변경

- 앱 작업: 이슈 #52, PR #54, `feat/#52-branding`.
- 홍보 이미지: 이슈 #53, `add/#53-appstore-assets`.
- 다음 업데이트 준비 버전: **1.0.2 (4)**. 새 버전의 스토어 업로드·심사 제출은 수행하지 않았다.

## 변경

사용자가 제공한 1080×1080 RGB 원본을 Design/Brand에 보존하고 앱 내부 로고에 원본 픽셀 그대로 적용했다. AppIcon은 같은 이미지의 1024×1024 RGB 출력이다. 로고에 별도 서린 배지를 추가하지 않았다. 화면 오른쪽 하단 서린 서명은 기존 에셋을 유지한다.

메인 색상 #1B34A8, 안내 배경의 보조색 #6071C2, 다크 강조 #AEBBFF를 공통 색상에 적용했다. 주요 버튼·탭·선택 테두리·슬라이더와 온보딩·홈의 안내 배경을 일관되게 표시한다. 삭제·오류·완료 의미 색상은 유지한다.

## 검증

- 시뮬레이터 빌드 성공, 실제 번들 1.0.2 (4) 확인.
- 아이폰 화면 흐름·촬영, 온보딩, 최대 글자 설정 3건 및 아이패드 화면 흐름·촬영 1건 통과.
- 최초 큰 글자 검증의 실행 인자만으로는 다크 모드가 반영되지 않은 점을 캡처에서 확인했다. 전용 시뮬레이터 자체를 dark로 변경하고 해당 테스트만 추가 재실행해 통과·시각 확인한 뒤 light로 복원했다. 총 4개 관련 테스트, 실행 5회이다.
- 주요 버튼의 흰 글자 대비 약 9.98:1, 다크 강조와 #1C1C1E 배경 대비 약 9.20:1.
- 로고 원본 픽셀 보존, 앱 아이콘 1024×1024 불투명 RGB 확인.
- iPad 촬영 테스트의 회전 요청 첨부 일부가 세로 크기로 반환되어 홍보 원본에는 검증된 세로 8장만 사용한다. 이번 작업에서 물리 기기와 실제 멀티태스킹 창 조절은 검증하지 않았다.

## 홍보 이미지

기본 글자 크기의 실제 새 화면으로 아이폰 1179×2556, 1320×2868, 아이패드 2064×2752에 각 7장, 총 21장을 생성했다. 상태 표시줄의 시간·배터리는 제외하고 기기 목업·기능별 제목과 설명을 유지했다. 첫 장은 새 TCON 로고와 은은한 하단 서린 로고를 배치했다. 큰 글자 검증 화면은 업로드 이미지에 사용하지 않는다.

원본 16장은 Captures/v1.0.2에, 최종 이미지는 ko-KR에, 색상·로고 원본과 UI 검증 화면은 Design/Brand에 나누어 보존한다. 최종 manifest는 앱 버전·빌드·브랜드 원본 해시·표현 개정·캡처 출처와 해시를 기록한다. 21장의 크기·RGB 불투명도·배치·기기 화면 채움 검사를 통과했다. 같은 브랜드 개정에서 표지 해시를 검사하는 모드를 유지하며 기기별 표지 3장의 재생성 해시 일치도 통과했다.

확인용 자료는 문서/SEOLIN_배포자료/TCON의 1.0.2 폴더에 보관한다. 기존 공개 제출 1.0.1 (3)의 기록은 이전 출시 문서에 유지한다. App Store Connect 상태 조회 연결이 응답하지 않아 현재 심사 상태는 재확인하지 못했다.
