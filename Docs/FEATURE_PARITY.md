# 기존 앱 기능 대응표

| 기존 기능 | iOS 화면 / 동작 |
| --- | --- |
| 여러 장 이미지 추가 | 홈의 사진 보관함 / 폴더 안 +의 사진 보관함·파일 선택 |
| TCON·증명·여권·직접 규격 | 전체 설정의 프리셋·가로·세로 |
| 최대 용량 입력 | 전체 설정·저장 화면 |
| 원본 용량 유지 옵션 | 고화질 저장·용량 제한 없음으로 정확한 의미 표시 |
| 흰색·투명·원본 배경 | 전체 설정과 개별 배경 도구 |
| 전체 밝기·개별 밝기 | 전체 설정과 밝기 도구 (가산 방식 보존) |
| 얼굴·균형·상체 가운데 | 전체 설정과 개별 구도 도구 |
| 명치까지·얼굴 크게 | 상반신·얼굴 크게 선택 |
| 아래로 보일 범위·얼굴 크기 | 구도별 슬라이더 및 숫자 직접 입력 |
| 머리 위 여백 | 전체·개별 구도에서 비율 입력 |
| 자동 얼굴 인식·방향·기울기 | 가져온 직후 기존 엔진으로 자동 처리 |
| 인물 기준 자동 정렬 | 맞춤 도구 토글, 제스처 종료 시 적용 |
| 크기·좌우·상하 | 제스처 및 맞춤 도구의 정밀 조절 |
| 기울기·좌우 90도 | 회전 도구, 회전 제스처, 0도 맞춤 피드백 |
| 원위치 | 초기화 (네이티브 버전에서는 원래 자동 방향도 복구) |
| 3등분·중앙·눈높이·머리 여백 | 미리보기 안내선 버튼 |
| 개별 삭제·모두 지우기 | 편집 삭제·길게 누르기 다중 선택/모두 선택 후 삭제 |
| 개별·전체 저장 | 선택된 대상의 저장 화면 |
| ZIP 저장 | 저장 화면의 ZIP 파일 선택 |
| JPG 압축·PNG·원본 기반 인코딩 | 원본 엔진 사용, 실제 크기/용량 검증 후 전달 |
| 라이트·다크 모드 | 시스템 색상 기반 화면 |
| 서린 링크 | 앱 정보의 서린태권도 링크 |

## iOS에서 추가한 동작

- HEIC/HEIF와 EXIF 방향 정규화, 카메라 촬영
- 기본 사진 선택창·파일 선택창·공유창·사진 앱 저장
- 파일 내보내기의 동일 이름·PNG 충돌 방지
- 일부 사진 선택 저장·삭제, 확인 필요 필터
- 사진별 구도 유지, 전체 적용 시 개별 변경 초기화 선택
- 저장 파일이 용량 조건을 만족하지 않거나 배경 처리에 실패하면 설명 후 재설정 가능
- 웹폰트 의존성 제거, 외부 네트워크 접근 차단

## 폴더 관리

- 홈·파일 하단 탭, 폴더 생성·이름 변경·삭제
- 홈에서 가져온 사진은 미분류, 폴더 안에서 가져온 사진은 해당 폴더에 저장
- 사진 길게 누르기 → 다중 선택 → 폴더 이동·선택 저장·붉은 테두리 삭제 버튼
- 사진 원본·편집값·얼굴 정렬·폴더·전체 설정을 앱 재실행 후 복구
- 폴더 삭제는 사진을 미분류로 이동, 사진 삭제는 선택된 앱 내 작업만 제거
- 빈 이름·중복 이름 방지, 저장 실패와 복구 실패 안내 및 재시도
- 사진 규격 선택은 진한 남색 배경·흰색 글자, 원본 안내는 저장 버튼 아래

## 보존한 알고리즘과 한계

얼굴·랜드마크·인물 분리 모델, 머리카락 경계 보정, 흰 도복 분리, 정수리 및 상체 측정, 원본 기반 렌더링과 JPEG 품질 탐색을 그대로 사용합니다. 모델 결과는 사진에 따라 차이가 있으며 실제 수련생 사진에서 도복·머리카락 경계를 확인해야 합니다.

미리보기는 가벼운 이미지로 표시하지만 저장은 원본에서 다시 렌더링합니다. 오류 시 저화질 미리보기로 몰래 저장하던 원본의 폴백은 iOS 내보내기에 사용하지 않습니다.
