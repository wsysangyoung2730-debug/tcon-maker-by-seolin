- 최종 앱 소스: develop `7acc018` (PR #54·#55·#57 포함)

- 작업 이슈 #58, 브랜치 `setting/#58-appstore-1-0-2`

## 배포 빌드

2026-10-19 Release 서명 Archive 성공. 아카이브 안의 Info.plist에서 실제 버전 1.0.2, 빌드 4, Bundle ID를 확인했다. 03:38 KST에 `Upload succeeded`, `EXPORT SUCCEEDED`를 확인했다. 기존 UI 검증은 반복하지 않고 배포용 서명·Apple 업로드 검사를 진행했다.

아카이브와 업로드 결과는 문서/SEOLIN_배포자료/TCON/Builds/1.0.2-build4에 보관한다. 자격 증명·인증서·심사 연락처는 저장소에 기록하지 않는다.

## 스토어 자료

1.0.1은 App Store Connect에서 ‘배포 준비됨’으로 확인했다. 1.0.2 업데이트를 생성하고 새로운 로고·색상·iPad 홈 배치에 대한 업데이트 설명과 심사 메모를 입력했다. 지원 URL, 심사 연락처, 수동 출시 설정을 유지한다.

기존 스크린샷 21장 제거에 대한 사용자 확인 후, 한국어 iPhone 중형 1179×2556·대형 1320×2868·iPad 2064×2752에 각 7장의 최신 홍보 이미지를 등록했다. 01–07 순서를 확인했다. iPad 2페이지는 새 세로 홈의 실제 화면이며 설정 3페이지도 갱신된 캡처를 사용한다. 스크린샷 연결 해제는 자산 보관함 원본을 삭제하지 않는다.

헤더 및 검색 결과 추가 설정은 사용자의 후속 요청으로 이번 작업에서 제외했다.

## 처리 상태

Apple의 빌드 처리가 완료되어 1.0.2 업데이트에 빌드 4를 연결하고 저장했다. App Store Connect의 빌드 표에서 버전 1.0.2·빌드 4를 확인했고 저장 버튼이 비활성화되어 저장 완료 상태임을 확인했다.

현재 상태는 **제출 준비 중**이다. 이번 작업은 새 빌드와 스토어 자료 반영까지 완료했으며, 심사 제출 및 공개 출시는 수행하지 않았다. 수동 출시 설정을 유지한다.
