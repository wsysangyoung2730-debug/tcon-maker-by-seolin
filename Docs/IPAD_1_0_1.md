# 1.0.1 아이패드 화면 개선

이슈 #48, 브랜치 `feat/#48-ipad-workspace`.

- 실제 창 너비 820pt 이상이며 일반 글자 크기일 때 홈·편집·저장을 두 열로 표시한다.
- 홈은 예시 사진과 가져오기·규격 설정을 나란히 배치한다.
- 편집은 큰 미리보기 옆에 조절 패널을 배치하고 각각 스크롤할 수 있다.
- 폴더·사진 목록은 최대 1320pt까지 활용한다. 하단 저장·삭제 버튼은 적절한 폭으로 제한한다.
- 좁은 창·최대 접근성 글자 크기에서는 세로 배치로 돌아간다.
- iOS 18 이상 아이패드 설정 창은 페이지 크기로 표시한다.

## 검증

Debug 시뮬레이터 빌드 성공. 관련 최종 UI 테스트 5건 통과: 아이패드 13형 세로·가로 화면과 최대 글자 크기 2건, 아이패드 mini 1건, 아이폰 캡처·사진 선택 진입 2건. 기존 사진 분석 테스트는 반복하지 않았다. 물리 아이패드와 실제 Split View 창 크기 조절은 이번에 확인하지 않았다.

1.0.1 (2) Release 서명 아카이브·App Store Connect 업로드 성공. 1.0.1의 실제 새 화면으로 21장 홍보 이미지를 생성하고 불투명 RGB·크기·배치·표지 보존을 검사했다. 개인정보처리방침 연결은 후속 별도 작업에서 빌드 번호를 올려 반영한다.
